# Tanolist

4択で覚える自分専用の単語帳 PWA。GitHub Pages で公開して iPhone のホーム画面に追加して使う。

## 単語リストの追加

`lists/` に `.md` ファイルを置くだけ。最初の `#` 見出しがリスト名、以降の 1 行が 1 ペア。

```md
# 韓国語 - ハンケン5級レベル
lang: ko-KR

- 사과 : りんご
- 학교 : 学校
```

区切りは `:` `：` `|` `=` タブのどれでもよい。

`lang:` は回答時に単語側を読み上げる言語(`ko-KR` `en-US` `zh-CN` など)。
省略した場合は文字の種類(ハングル・かな・漢字・英字)から推測する。

GitHub Pages 上では GitHub API で `lists/` を自動走査する。
ローカル確認時(と API 制限時)は `lists/index.json` のファイル名一覧を使うので、ファイルを増やしたらここにも追記しておく。

## 端末に保存されるもの

選択中のリスト・不正解カウンタ・○×表示秒数は localStorage(端末ごと)に保存される。
